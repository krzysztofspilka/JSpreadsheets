SVAR DataGrid is a free, open-source component that helps you integrate powerful, feature-rich and lightning-fast data tables into your apps. It efficiently handles large datasets and supports virtual scrolling, in-cell editing, sorting, filtering, and full customization to fit complex projects. Supports TypeScript and comes with detailed docs and demos. 

The data grid is available for React and Svelte (not wrappers, native solutions):
* [SVAR React DataGrid](https://svar.dev/react/datagrid/)
* [SVAR Svelte DataGrid](https://svar.dev/svelte/datagrid/)


#### Key Features

* High performance (virtual scrolling for rows and columns)
* In-cell editing
* Custom HTML for cells
* External edit form for grid data
* Sorting by multiple columns
* Filtering (including complex logic)
* Paging
* Frozen columns
* Expandable/collapsible columns
* Row reordering with drag-and-drop
* Context menu
* Tree-like structure
* Keyboard navigation
* Accessibility: compatibility with WAI-ARIA 
* RestDataProvider for easy backend data binding
* Undo/redo
* Print support
* Responsive mode
* Easy customization with CSS
* TypeScript support
