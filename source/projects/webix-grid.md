Webix Grid is a powerful and flexible JavaScript component for displaying, editing, and managing large datasets. 
It combines a lightweight design with rich functionality and compatible with any framework, such as React, Vue, or Angular.

#### Features:

* Data virtualization (lazy rendering)
* Lazy loading
* Framework-agnostic design
* Area selection
* Cell editing with advanced editors
* Colspans and rowspans
* Column grouping with expand/collapse
* Column header menu
* Filtering (with dropdowns and calendar support)
* Multiple themes (Material, Flat, Compact, Contrast, Willow, Dark)
* Pagination
* Sorting (supports multi-column sorting in UI and any custom rules in API)
* Sparklines (line, area, bar, spline, pie)
* Subrows and subviews
* Vertical headers
