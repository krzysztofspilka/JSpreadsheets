DHTMLX React Spreadsheet is a UI component for React applications that provides Excel-like spreadsheet functionality directly in the browser. It allows developers to embed a full-featured spreadsheet editor into React apps, with support for cell editing, formatting, formulas, multi-sheet workbooks, and XLSX file exchange. The component follows a declarative, props-based API, integrates with Redux and Next.js, and ships with TypeScript support out of the box.

## Key Features

* Excel-like in-browser cell editing and rich formatting
* 90+ built-in formulas and number formatting
* Multi-sheet workbooks with add, remove, and rename support
* Sorting, filtering, and searching
* XLSX import and export
* Undo/redo
* Cell styling and merging
* Frozen panes and data validation
* Row and column operations (add, delete, hide, resize, auto-fit)
* Configurable toolbar and context menu
* Cell locking and read-only mode
* Built-in themes with CSS variable customization
* Localization support
* Redux Toolkit integration
* Next.js App Router support
* TypeScript support with bundled type definitions

## Installation

The evaluation version is available on the public npm registry with no additional configuration required. It includes a free 30-day trial period and technical support via the [community forum](https://forum.dhtmlx.com/c/spreadsheet/).

```bash
npm install @dhtmlx/trial-react-spreadsheet
```

or with yarn:

```bash
yarn add @dhtmlx/trial-react-spreadsheet
```

The commercial package is distributed via the private npm registry. Before installation, log in to your account in the Client Area to obtain your access credentials.
